## 💋 Killer Kiss — Social Web Game  
**Java · Spring Boot · PostgreSQL (Supabase) · Docker · HTML/JS**

Killer Kiss is a social elimination game played via email.  
The backend is deployed on **Render.com**, and the database runs on **Supabase (PostgreSQL)**.


**Live App:** https://killer-kiss.onrender.com/public.html  
> **Note:** If the application is inactive, it may take a few seconds to start up the services (Render free-tier).
